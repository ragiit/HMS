# Environment Setup (.env)

`docker-compose.yml` membaca variabel environment dari file `.env` yang **berada di folder yang sama** dengan `docker-compose.yml`, yaitu `HMS.API/`.
> **Catatan**: File `.env` sudah di-ignore oleh `.gitignore` (karena berisi secrets). 
> Anda harus membuat file `.env` sendiri secara manual dengan menyalin contoh di bawah ini.
